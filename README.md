# Predikta 4.0
Odpri index.html v Chrome ali objavi vse tri datoteke (index.html, slovar.js, kontekst.js) v korenu repozitorija GitHub. Settings → Pages → Deploy from a branch → main → / (root) → Save.
Predikcija deluje lokalno. F2 vklopi/izklopi mikrofon, puščici izbirata, Tab potrdi brez presledka, Esc skrije predloge, F4 prebere zapis. Glasovni vnos zahteva podporo brskalnika in dovoljenje; zvok lahko obdeluje zunanji ponudnik. Viri in omejitve so navedeni v zavihku O aplikaciji.
